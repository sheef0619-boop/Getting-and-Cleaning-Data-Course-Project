# Getting and Cleaning Data Course Project

## Overview

This repository contains my solution for the **Getting and Cleaning Data Course Project**.

The project uses the **Human Activity Recognition Using Smartphones Dataset** and creates a tidy data set containing the average of each selected measurement for every subject and activity.

The course project requires a script that:

1. Merges the training and test data.
2. Extracts measurements on the mean and standard deviation.
3. Uses descriptive activity names.
4. Applies descriptive variable names.
5. Creates a second tidy data set with the average of each variable for each subject and activity.

## Files

- `run_analysis.R` — R script that performs all five required steps.
- `CodeBook.md` — describes the data, variables, and transformations.
- `README.md` — project documentation.
- `tidy_data.txt` — generated by `run_analysis.R` after the script is executed.

## How to run

### 1. Install R

Use R or RStudio.

### 2. Place the script in a working directory

For example:

```text
Getting-and-Cleaning-Data-Course-Project/
├── run_analysis.R
├── README.md
└── CodeBook.md
```

### 3. Run the script

Open RStudio, set the working directory to the project folder, and run:

```r
source("run_analysis.R")
```

The script automatically downloads and extracts the UCI HAR Dataset if the `UCI HAR Dataset` folder is not already present.

### 4. Output

After successful execution, the script creates:

```text
tidy_data.txt
```

The final tidy data set contains **180 rows** (30 subjects × 6 activities) and **68 columns** (subject, activity, and 66 selected measurements).

You can read it with:

```r
tidy_data <- read.table("tidy_data.txt", header = TRUE, sep = "\t")
View(tidy_data)
```

## Dataset source

The original data set is the Human Activity Recognition Using Smartphones Dataset, Version 1.0.

The data were collected from the accelerometers and gyroscopes of a Samsung Galaxy S smartphone.

## Reproducibility

The analysis uses only base R functions. No additional R packages are required.

The script is designed to be reproducible: it checks for the source data, downloads it if necessary, performs the cleaning steps, and writes the final tidy data set.

## Result

The final data is organized so that:

- each row represents one subject/activity combination;
- each measurement variable is a separate column;
- each measurement contains the mean value for that subject/activity combination.

This is the independent tidy data set requested in step 5 of the course project.
